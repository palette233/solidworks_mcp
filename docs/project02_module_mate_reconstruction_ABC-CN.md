# 项目02：模组级配合重建 A/B/C 实验

## 1. 实验目标

验证“不使用布局约束求解，仅使用项目02子装配体和导出的同层级配合关系”能否恢复原型装配体。

统一输入：

- 原型：`FL9A24D062A000.001.SLDASM`
- 顶层节点：A100、A180、A200、A300、A500、A600、A700、A800、两个 T401，共10个实例
- 跨模组配合：27条，包括重合、距离、平行、槽口和宽度配合
- 固定基准：A600箱体
- 本实验不运行布局约束求解，也不运行B-rep干涉检查

## 2. 三组实验定义

### A：原型初始位姿＋配合

先用原型变换放置全部模组，再重建导出的配合。该组验证配合数据和重建接口能否保持原型布局。

### B：非原型初始位姿＋纯配合

只保留A600原型基准，其余模组放到确定性的非原型初始位置，再仅靠配合求解。该组验证“只有子装配体和配合”是否足以唯一恢复原型。

### C：配合＋残差锚点

根据B组的欠约束和位姿误差，为相关节点补充原型残差位姿，再重建同一套配合。该组验证少量补充信息能否恢复原型。

当前C组为保守Demo：残差锚点使用被选模组的完整6-DOF原型变换，还未细化成最少的单轴距离、方向或安装基准参数。

## 3. 实验结果

| 实验 | 配合重建 | 保存重开 | 原型位姿匹配 | 关键结果 |
|---|---:|---:|---:|---|
| A | 24/27 | 通过 | 10/10 | 原型初始位姿可与已恢复配合共同保持原型布局 |
| B | 24/27 | 通过 | 7/10 | 仅靠当前配合不能唯一恢复全部节点 |
| C | 24/27 | 通过 | 10/10 | 补充残差锚点后恢复全部模组位姿 |

B组不匹配节点：

- A800：平移误差约243.65 mm，旋转保持一致；
- T401实例1：平移误差约1206.49 mm，且方向不一致；
- T401实例2：平移误差约894.10 mm，且方向不一致。

C组自动补充的锚点为A500、A700、A800和两个T401实例。A500、A700在B组虽落到原型位姿，但约束状态仍非完全约束，所以按保守规则一并补充。

三组共同未重建的配合为`重合14`、`距离10`、`距离28`。三条均涉及T401顶层零件，当前面恢复无法从该组件的装配上下文得到实体/面索引，因而在创建配合前即被拒绝。其余24条配合均创建并在重开后保留。

## 4. 结论

1. **子装配体＋当前配合关系并不足以保证唯一恢复原型。** B组已经形成直接证据：配合创建数与A/C相同，但仍有3个实例偏离原型。
2. **初始位姿或等价安装基准是必要补充信息。** A组和C组均达到10/10，证明补充位姿信息可闭环。
3. **当前最合理的中间表达应为“配合图＋少量锚点/基准”，而非只有配合边。** 后续可把完整6-DOF锚点逐步压缩为工程可解释的端面、孔轴、距离、方向和操作侧基准。
4. **面稳定寻址仍是剩余核心技术问题。** T401需要增加零件文档级持久引用恢复或更可靠的几何指纹映射，才可能达到27/27配合。
5. **本实验只验证装配关系重建，不证明实体无干涉。** 如需工程放行，仍应另做分级AABB/B-rep检查。

## 5. 实现与验证

新增能力：

- `RunModuleMateReconstructionExperiment`：支持`source_pose`、`mate_only`、`residual_anchors`三种模式；
- 支持重合、距离、平行、槽口和宽度配合重建；
- 按源特征恢复宽度/槽口高级参数和距离翻转信息；
- 面定位采用“实体/面索引优先、几何指纹回退”；
- 自动保存、关闭、重开，复核配合数、位姿误差和约束状态；
- Python脚本按A→B→C顺序运行，并依据B组结果选择C组锚点。

验证结果：

- Release构建通过；
- 非集成.NET回归测试320/320通过；
- Python实验脚本语法检查通过；
- A/B/C三个目标装配体和结构化JSON结果均已落盘。

实验过程中曾尝试使用`CreateMate`直接绑定距离配合实体，并打开T401零件文档做面回退；SolidWorks发生进程级退出且未生成目标文件。该不稳定路径已回退，没有混入最终A/B/C结果。

## 9. 2026-09-07 恢复为当前探索主线

本方向现已重新启用，目标仍限定为：**不运行布局约束求解，仅依靠项目02子装配体、导出的配合图和最少必要安装基准，恢复项目02原型。** v42依赖消融与完全去原型布局求解暂时冻结，恢复入口保留在`docs/project02_dependency_ablation-CN.md`，两条路线的数据和结论不得混用。

恢复时已核实以下证据仍完整存在：

- 项目02全量模组配合图：10个实例、27条跨模组配合、10个配合束；
- A500–A700“距离8”单配合完成导出、面恢复、新装配体创建、保存重开闭环；
- A/B/C三组装配体及结果JSON均存在；A/C为10/10原型位姿，B为7/10；三组均为24/27配合；
- 共同缺失仍为T401相关`重合14`、`距离10`、`距离28`；
- 忽略T401后，B组唯一偏离原型的非T401模组仍是A800，当前高置信度判断为沿世界X方向保留1个平移自由度；
- A500、A700虽位姿正确，但在三组中均显示过约束，需要区分原型配合本身冗余、重建语义重复和SolidWorks求解顺序影响。

### 当前唯一推进顺序

1. **T401最小复现**：仅用A600/A200/T401建立小装配体，逐条验证3个失败配合的端点归属、零件文档持久引用及几何指纹回退；先达到27/27可创建，不重复加载完整总装做盲测。
2. **自由度与冗余分析**：对A800进行六自由度微扰和配合秩审计；对A500、A700逐条增量加配合，定位首次过约束的边。
3. **最小工程锚点**：把C组5个完整6-DOF原型变换替换为可解释的安装端面、中心面、孔轴、单轴距离或方向；A600作为唯一固定根节点。
4. **非原型初始位姿重建**：所有非根模组从确定性的扰动位置插入，只应用27条配合和最小锚点，保存、关闭、重开后复核配合数量、求解状态、剩余自由度和原型位姿误差。
5. **独立验收**：配合恢复闭环完成后再单独运行AABB/条件B-rep；实体无干涉不属于本阶段成功条件。

### 本阶段成功判据

- 27/27跨模组配合被创建并在重新打开后保留；
- 除明确记录的冗余配合外，无未知过约束或悬空实体；
- 不使用原型顶层初始位姿作为隐藏输入；
- A600固定，其余模组由“配合＋最少工程锚点”恢复到约定的位置/角度公差；
- 结果JSON能分别解释每个模组的约束来源、剩余自由度和位姿误差。

修改意义：把此前“配合能建出24条但为何不能唯一恢复”的探索，收敛成面寻址、约束秩和最小锚点三个可分别验证的问题；同时将配合复原与布局求解、实体干涉检查解耦，避免再次用原型初始位姿掩盖欠约束。

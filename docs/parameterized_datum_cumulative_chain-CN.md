## 实现与修改意义

1. 全局接口规划器桥接真实 CAD 定义 ID 与接口目录身份；显式 `datum_placement_demo` 可进入新定位路径，默认 `direct_installation` 不会自动降级。
2. 将独立两模组验证证据转换成现有关系目录发布，继续使用原有自然语言编译器、面注册表和 CAD 事务执行器。不把参数化定位发布冒充孔槽机械互换。
3. 多发布累计链改为有序阶段列表，支持直接安装与定位模式交错。前一阶段成功产物作为下一阶段输入，源文件/发布/参数/自然语言审计记录按摘要绑定。
4. 新增 `confirmedModuleSelections`，将工程师确认的具体模组逐项传入自然语言编译器。未确认、数量不符、未知 ID 均拒绝；自然语言文本无需包含内部编号。
5. 参数变化产生新契约/新配方，不能借用旧参数的成功证据。参数仍为 Demo 的位置表达，不是厂商签认尺寸。

这些修改的意义是把已经单独跑通的定位能力接回累计装配主线，而不是继续为每个组合写一个专用装配执行器。

## 2026-10-26 自然语言位置参数候选

参数化定位候选现在可接收受限、可审计的中文位置指令，例如：


编译器只接受“基座纵向、基座横向、支承高度/间隙”三类语义轴，并统一转换为米。裸写`X/Y/Z`会被拒绝，因为不同项目坐标系的轴向定义不能默认相同。相对移动必须同时提供已经确认的当前三项参数，并明确写出“其余位置参数保持不变”；绝对指令必须一次给齐三项，或在已有完整当前值的前提下明确保持其余值不变。

# 项目02求解方案展示层

## 目标

在执行SolidWorks Replay前完成一次快速闭环：

```text
通用约束与求解原则
→ 项目02去原型离线求解
→ 展示预计布局和约束结果
→ 人工观察明显不合理项
→ 决定是否继续校准通用规则
```

展示层不使用原型模组位姿参与求解。项目02原型只应在后续对比评测阶段使用。

## 使用方式

1. 启动后端和前端。
2. 打开 `http://127.0.0.1:5173`。
3. 点击页面顶部的“求解项目02”。
4. 查看布局轮廓、方向、工艺点、约束统计和右侧观察项。
5. 点击任一模组查看其中心、方向和点位定义。

离线求解接口：

```text
POST /api/demo/cases/project02/solve-preview
```

输出文件：

- `demo/layout_previews/project02_solution.json`：完整求解结果；
- `demo/layout_previews/project02_preview.json`：展示层数据。

本轮展示结果为：

- 工艺硬约束：13/13通过；
- 空间硬约束：11/11通过；
- 双阀行程包含：通过；

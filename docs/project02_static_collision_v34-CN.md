## 1. 本轮目标

把此前“生成方案后对大量组合执行B-rep”的流程改为：

```text
求解硬约束
  → 普通模组膨胀AABB硬分离
  → 保存装配体真实世界AABB宽相
  → 复用相对位姿未变的历史精检证据
  → 按风险分批执行条件B-rep
  → 首个硬干涉立即停止并回灌约束
```

本轮只处理静态实体干涉；运动扫掠、软管/拖链和维护空间不在当前里程碑内。

## 3. 新增功能

### 3.1 相对位姿证据复用

新增 `static_collision_closure.py`，用以下条件判断旧精检证据是否可复用：

1. 精检必须完整返回；
2. `HasInterference=false`；
3. `FailedBodyPairCount=0`；
4. 当前方案中该模组对的相对U/V/方向与证据方案一致；
5. 两个源CAD文件的修改时间不晚于精检证据。

意义：全局移动整套布局不会触发无意义的重复B-rep；任何成对相对移动或源CAD修改都会自动使旧证据失效。

### 3.2 保存装配体真实世界AABB宽相

不再仅依据展示层二维包围盒决定精检范围。规划器读取v33保存后回采的真实世界三维AABB，并在每侧膨胀10 mm后判断严格分离。

当前结果：

- 条件策略组合：18组；
- 世界AABB直接排除：4组；
  - A200–A500；
  - A200–T401；
  - A300–A700；
  - A500–A700；
- 仍需条件B-rep：14组。

意义：减少实体精检次数，同时不把包围盒重叠误判成实体干涉。

### 3.3 风险分级执行

当前14组待检组合分为四级：

| 优先级 | 模组对 | 处理原则 |
| --- | --- | --- |
| P0 | A100–A200 | 首要历史阻塞；单独检查，失败立即停止 |
| P1 | A200–A700、A200–A800 | CCD服务区和传输门洞组合 |
| P2 | A100–A180、A100–A500、A180–A800、A300–A800、A500–A800 | 历史干涉回归组合 |
| P3 | A100–A300、A100–A700、A100–A800、A180–A200、A200–A300、A700–A800 | 前三级通过后再检查 |

意义：A100–A200未通过时不再浪费时间检查后续13组。

### 3.4 首个硬失败即停

`capture_leaf_interference_details.py` 新增 `--stop-on-first-interference`：

- 检查不完整、存在实体干涉或存在失败叶体对时立即停止；
- 批结果记录请求数量、完成数量和是否提前停止；
- 已完成的JSON证据仍然保存。

### 3.5 优先精检执行器

新增 `run_project02_priority_brep_gate.py`：

- 每次只执行一个优先级批次；
- 自动复用已经完成的单对结果；
- 失败时更新机器状态为“约束回灌后重新求解”；
- 通过后才允许进入下一批；
- SolidWorks进程数量超过1时拒绝运行，避免COM/MCP绑定错误文档。

### 8.3 当前结论

当前状态不是网络中断，也不是 B-rep 算法失败，而是估算几何语义之间存在可复现的约束冲突：

- A500 的临时校准服务点/可达区把它限制在 A200 与 A700 之间；
- A700 多包围盒向扫描侧移动时与 A180 膨胀占用体冲突；
- A180 继续避让又会触发龙门边界；
- 继续逐对平移只会在 A100–A200、A100–A500、A200–A500、A500–A700、A180–A700 之间转移干涉。

因此 `staticCollisionReady=false`、`productionReady=false`。机器状态见：

本轮 CAD 调用结束后仍有11个无窗口 `SLDWORKS.exe`，普通权限 `Stop-Process`、`taskkill` 和 UI 正常关闭均不可用；在管理员任务管理器清理或 Windows 重启前不得继续启动 Replay/B-rep。

## 13. 2026-08-27：v46 结论更正与 v48 原型基线等价闭环

### 13.1 更正原因

- v46 后续完整覆盖审计发现，若叶级占用体没有覆盖全部结构，`leaf AABB hit=0` 不能直接推出实体不干涉。补做精检后，A200–A800 实际存在 1 对干涉，因此第 12 节的“静态碰撞全部闭合”结论被本节取代。
- v47 收紧 CCD–传输相对窗口后，A200–A800 精检降为 0；但 A800–A700 得到 8 对精确接触。

### 13.2 v48 验收规则与结果

1. v48 使用 A700–A800 的原型支持相对服务窗口重新求解，通过工艺 `23/23`、空间 `13/13`、交互 `37/37`。
2. 对原型和 v48 的 A800–A700 分别执行完整叶级 B-rep，均为 8 对；按叶组件实例身份比较，新增集合和缺失集合均为空。
3. 这 8 对位于 A700 A720/A730 与 A800 A860 的共享/嵌套机构边界。对该组合采用“不得新增原型基线之外的干涉”，其他普通组合仍要求零干涉；没有把原型绝对位姿输入求解器。
4. A100–A200、A100–A800、A200–A800 和 A500–A700 的相对变换均在 `1e-8` 阈值内，复用各自完整零干涉证据。
5. 最终静态状态为 `STATIC_COLLISION_BASELINE_EQUIVALENT_REOPEN_RETRY_REQUIRED`、`staticCollisionReady=true`、`productionReady=false`。v48 保存成功，但磁盘隔离重开时 SolidWorks 在 `OpenDoc6` 阶段退出，因此重开位姿复核未完成。

### 13.3 修改意义

本轮把“零干涉”从单一计数改成可追溯的集合门禁：普通模组对要求空集合，共享/嵌套边界要求相对原型无新增集合；同时只有结构覆盖完整时才允许用叶盒严格分离跳过 B-rep。这样既减少不必要精检，也不会因不完整宽相或原型固有接触给出错误结论。

# 功能测试2—6验收记录（2026-10-26）

## 测试范围

按用户要求，本轮不测试自然语言入口，执行以下五类测试：

1. 非原型位姿与重复性；
2. 变序累计装配；
3. 失败关闭；
4. 暂停、恢复与幂等性；
5. 性能与耗时证据。

碰撞/B-rep、实际紧固、承载、维护空间、工艺合理性和生产放行仍不在本轮范围。

机器可读总表：`demo/acceptance_stage_2_6_20261026/acceptance-summary.json`。

## 1. 非原型位姿与重复性

- 状态为已发布；
- 允许CAD执行；
- 禁止原型顶层位姿；
- 发布与CAD证据可追溯。

先复用不可变发布和原始CAD结果对14项进行分层证据重放；随后从中选择3项，以第二种非原型初始位姿进行新的真实CAD插入：

|---|---:|---:|---:|
|P000→JJ00|230.339 s|3/3|`4.441e-16`|
|A500→AA00|124.659 s|3/3|`1.027e-15`|
|A300→JJ00|115.463 s|3/3|`4.441e-16`|

三次主动重跑均完全约束、求解干净、保存关闭重开参数一致、源文件不变，并在结束后关闭输出。三项合计`470.461 s`。其余11项仍属于不可变证据重放，不把它们表述为本轮新CAD运行。柔性G000的既有双非原型初始位姿外部根位姿重复性证据继续有效。

同时真实重开三种基座的最终六模组装配体：

## 2. 变序累计装配

复核以下真实CAD链：

- AA00标准顺序；
- AA00变序；
- A600跨型号变序；
- A000跨型号变序。

检查内容包括组件集合、配合状态、累计检查点、保存重开、源文件不变和变序后的最终语义一致性。专项回归：`98 passed in 8.01s`。

结论：已登记且彼此无前置依赖的步骤可以改变追加顺序；该结果不等于任意排列均合法，仍须满足接口依赖和基座先存在等条件。

## 3. 失败关闭

覆盖摘要篡改、端口缺失、位置指令不完整、接口方向/间距不兼容、未知执行模式、未确认决策、发布证据不完整和输出路径超限等情形。所有异常均在CAD启动前或提交检查点前被拒绝。

专项回归：`109 passed in 13.32s`。

## 4. 暂停、恢复与幂等性

状态机测试验证：

- 当前步骤完成后在检查点边界暂停；
- 恢复时复用已提交检查点；
- 只重试失败步骤及后续尾部；
- 相同幂等键不会创建重复任务；
- 发布阶段失败可恢复而不重复运行CAD；
- 不允许跳过待执行项或改变队列顺序。

真实变序六模组证据还包含一次在第三阶段前注入失败：恢复时前两阶段均标记为`reused_committed_checkpoint`，仅继续执行后三阶段并最终通过。

专项回归：`48 passed in 6.19s`。

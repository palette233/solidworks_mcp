# 项目02：子装配体配合导出与重建 Demo

## 目标

在完整原型装配体中读取两个顶层子装配体之间的真实配合，记录配合类型、参数以及两个配合面的身份；随后仅插入这两个子装配体，在新装配体中找回对应面、重建配合、保存并重新打开复核。

## 已实现功能及意义

1. `ExportMatePair`：按两个顶层模组筛选直接配合，仅接收两个端点均为面的基础配合。意义：把“配合关系”与明确的面 A、面 B 一起持久化，而不是只保存组件名称和最终位姿。
2. `FindMatePairCandidates`：一次遍历顶层 MateGroup，再按端点所属模组分组和排序。意义：避免八个模组两两组合时重复遍历大型装配树。
3. `RoundTripMatePair`：新建装配体、插入两个源子装配体、恢复源变换、按体索引和面索引找回端点、调用 `AddMate5`、保存、重开并再次导出验证。意义：形成可机器判定的导出—重建—重开闭环。
4. 插入兼容回退：若 `AddComponent5` 首次失败，先单独加载子装配体，重新激活目标装配体后再次插入。意义：兼容项目02这类未预加载的大型真实子装配体。
5. 测试脚本支持候选搜索、只读检查和仅闭环模式，并统一使用绝对输出路径。意义：减少重复加载，同时避免 MCP 发布目录变化导致的相对路径冲突。

## 项目02真实验证

### 模组对与配合

- 模组 A：`FL9A24D062A500.001-1`（A500 校准模组）
- 模组 B：`FL9A24D062A700.001-1`（A700 清洁/称重模组）
- 源配合：`距离8`
- SolidWorks 类型：`swMateDISTANCE`
- 对齐：`swMateAlignANTI_ALIGNED`
- 实际距离：`0.05 m`（50 mm）
- 端点：2 个 `IFace2`

### 面身份

- A500 端：叶零件 `FL5A24D062A510012.01.SLDPRT`，实体索引 0，面索引 11，面积约 `0.001602 m²`。
- A700 端：叶零件 `FL5A24D062A710004.01.SLDPRT`，实体索引 0，面索引 3，面积约 `0.001080 m²`。
- 两端都通过 `BodyFaceIndex` 精确找回，未使用面积回退。

### 闭环结果

- 配合导出：1/1 可重建。
- 新装配体配合创建：成功，`swAddMateError_NoError`。
- 保存：成功，文件约 7.45 MB。
- 重新打开：成功。
- 期望/观察配合数量：1/1，一致。
- 期望/观察类型：`swMateDISTANCE` / `swMateDISTANCE`，一致。
- 自动候选回退：未使用。
- 最终状态：`SUCCESS`。

## 过程问题与修正

1. 首次闭环因检查导出和重建导出使用同一相对路径，被“禁止覆盖”安全门禁拒绝。已改为绝对路径，并加入 `--roundtrip-only`，避免重复导出。
2. 第二次闭环在新空装配体中首次插入 A500 失败。已复用通用组件插入的“预加载后重试”逻辑。
3. 修正后应用构建为 0 错误、0 警告；装配服务聚焦测试 17/17 通过；真实 SolidWorks 闭环通过。

# 多项目标定参数与约束迁移

## 1. 目标

把项目02已经验证的布局流程迁移到项目01、03、05、06时，只复用约束类型、求解顺序和验证策略，不直接复制项目02的坐标、距离、行程或允许接触清单。

统一流程为：

`模组识别 → 项目参数标定 → Top-3粗布局 → 人工目测选案 → 独立装配体生成/Replay → 条件B-rep → 保存重开复核`

## 2. 为什么必须建立项目标定包

“扫描器靠近输送线条码侧”“服务点进入双阀公共行程”“普通实体采用膨胀包围盒分离”等规则可以跨项目复用；但下列内容随设备结构变化，必须逐项目提取：

- 箱体操作面、安装平面及传输模组XYZ安装基准；
- 缓存扫码点、工作位、条码面和扫描光轴；
- CCD光轴、工作距离与视场；
- 双阀公共可达范围及阀间距；
- 标定、清洁、称重、排胶等服务点；
- 多包围盒占用体、维护空间和允许接触清单。

原型测量值可以作为粗布局基线，但必须标记为`prototype-calibrated`，不能伪装成厂商确认参数。

## 3. 统一证据模型

新增统一构建器：

- `apps/demo-backend/src/demo_backend/project_calibration.py`
- `scripts/build_multi_project_calibration_portfolio.py`
- 机器结果：`demo/layout_previews/multi_project_calibration_readiness.json`

每项证据统一记录：

- `status`：`available / partial / missing / not_required`；
- `authorities`：厂商确认、CAD配合/几何、PPT+CAD推断、原型标定或临时估计；
- `coarseLayoutRequired`：是否为当前项目粗布局硬输入；
- `coarseLayoutUsable`：当前证据是否足以放行Top-3；
- `productionConfirmed`：是否已经达到厂商或工程确认等级。

门禁含义：`top3SolveReady=true`只表示粗静态布局输入齐全，不代表运动、线缆/胶管、人体工学或生产参数已经验收。

## 5. 后续执行顺序

1. 先以项目02作为基准案例，确认A700-A800/A860接触是否允许，并补充供胶接口与当前求解范围声明。
2. 项目05按缺口矩阵依次采集扫描/CCD、服务点、双阀行程、多占用体；门禁通过后才生成Top-3。
3. 项目06先建立参数包与CAD路径索引，再按相同证据顺序标定；禁止继承项目02数值。
4. 每个新项目只在人工选定唯一候选后进入SolidWorks，先宽相筛选，再仅对结构/门洞/嵌套命中对执行叶级B-rep。

## 6. 本次功能修改意义

统一门禁把“规则可迁移”和“参数需重测”变成机器可检查的数据，而不是依赖口头约定。它可提前指出某项目能否求解、缺什么证据，并阻止把项目02坐标直接套用到其他原型；同时继续把昂贵SolidWorks/B-rep留到唯一候选之后。

离线定向回归共73项通过。完整`unittest discover`会进入现有`test_layout_preview`的高代价真实布局求解，首项约90秒后超时/报错；该测试路径与本次标定归一代码无直接依赖，因此本轮停止继续消耗求解时间，未启动SolidWorks或B-rep。

## 7. 2026-09-09 非首选候选实体化验证

项目01与项目03的第二候选均已从Top-3中独立选定并生成SolidWorks装配体：项目01的GN00沿U移动-30 mm，项目03的AH00沿V移动-30 mm。两案均保存重开成功，严格AABB 12/12通过，证明多项目流程已经支持rank 1之外的候选实体交付，而不是只能保存原型等价最优解。

本轮同时修复非首选方案的位姿审计基准：审计目标由原型位姿改为所选候选的目标变换。条件B-rep与安装接触精检尚未执行，因此两案仍是“粗布局实体候选”，不能作为生产零干涉结论。

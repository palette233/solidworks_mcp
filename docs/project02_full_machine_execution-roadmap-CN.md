# 项目02整机、动态工艺、通用执行器与性能优化台账

更新时间：2026-09-30

## 1. 总目标

在现有七模组静态闭环基础上，依次完成：

1. A200 CCD与两个T401供胶实例进入真正累计装配链；
2. A700动态配合、A100双阀全行程和工作区覆盖形成独立工艺门禁；
3. 任意合法子序列可以作为后台作业执行，支持检查点、取消、恢复和失败回滚；
4. A600/A800等高耗时B-rep基准按源几何、配置和相对位姿版本缓存，并能可靠失效。

所有阶段均遵循：**先离线规划和硬门禁，再执行CAD；先保存重开，再声明通过；失败必须保留证据且不得覆盖上一步产物。**

## 2. 阶段与验收标准

### 阶段A：九对象整机静态累计链

范围：现有A600、A800、A180、A700、A300、A500、A100，加A200及两个T401实例。

计划：

1. 从完整27配合图裁剪A200–A600、T401-1–A600、T401-2–A200的单步有效图；
2. A200登记机械安装端口、CCD光学端口和结构通道；
3. 两个T401分别登记安装/供胶接口和维护包络；
4. 修复同源文件多实例的目标识别和重开验证；
5. 依次累计插入、保存、关闭、重开；
6. 每步先做AABB，再对未能严格分离或属于嵌套/安装关系的组合做条件B-rep；
7. 形成45/45顶层对象对的完整覆盖报告。

通过条件：目标实例唯一、配合参数一致、静态光学/供胶验证通过、保存重开通过、无未接受的新实体干涉。

### 阶段B：动态工艺门禁

计划：

1. A700保留当前静态快照作为粗布局状态，另建动态配合图与可采样状态目录；
2. 至少验证A700清洁位、称重位、维护位三个离散工艺状态；
3. A100不做完整多体动力学仿真，先按原型/限位证据建立左右阀公共可达包络；
4. 用工作位1/2、扫描/CCD定位点、排胶点、校准点、清洁点、称重点验证覆盖；
5. 对包络边界与代表性极限位姿执行AABB和必要的条件B-rep。

通过条件：所有必需工艺点进入对应可达域，代表性状态无未接受干涉；未取得厂商限位时只能标记`prototypeBaselineAcceptedForCoarseLayout`，不得标记生产确认。

### 阶段C：通用异步作业执行器

计划：

1. 把自然语言解析结果编译成不可变执行计划；
2. 每一步记录输入装配体哈希、输出临时路径、CAD结果、AABB/B-rep结果和耗时；
3. 后台串行执行SolidWorks任务，提供创建、查询、取消、恢复接口；
4. 每步成功后原子提交检查点；失败时删除/隔离未提交的临时产物，并把上一检查点作为可恢复入口；
5. 支持合法子序列，但必须满足依赖闭包；不允许跳过硬门禁。

通过条件：单元测试覆盖成功、失败、取消、恢复、重复请求幂等和非法顺序；HTTP集成测试能观察完整状态机。

### 阶段D：B-rep版本化缓存

计划：

1. 缓存键包含源CAD内容哈希、配置、相对刚体变换、检查策略、工具/内核版本和基准证据哈希；
2. 不再把整个输出装配体哈希作为唯一复用依据，允许无关模组变化时复用未受影响的对象对；
3. 源几何、配置、相对位姿、策略或基准任一变化都必须失效；
4. 记录命中、失效原因、节省时间和重新计算范围；
5. A600/A800首次24.4分钟证据作为回归样例。

通过条件：相同对象对命中缓存；只移动无关模组仍命中；移动A600/A800、修改源文件或策略必定失效；伪造/不完整证据不得复用。

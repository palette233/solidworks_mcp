# 当前能力边界与兼容性分级

更新日期：2026-10-19

## 1. 已经具备的能力

- 从自然语言识别模组角色、顺序和连接意图；
- 返回多个具体模组候选并等待人工确认；
- 使用全局目录、语义端口和关系模板生成可编辑实例图；
- 通过面端点目录恢复配合所需的面、边和点；
- 编译逐包CAD事务，从非原型初始位姿插入子装配体；
- 创建重合、同心、距离、平行、宽度等真实SolidWorks配合；
- 保存、关闭、重开并复核配合参数；
- 支持累计装配、检查点、暂停、恢复和失败保留；
- 已完成多个项目内长链及部分跨项目直接安装实验。

## 2. 兼容性必须分级

“可以连接”至少包含五个不同层级，不得混用：

| 等级 | 判定内容 | 当前系统覆盖 |
|---|---|---|
| 角色兼容 | 都属于传输、扫描、校准等同一角色 | 已覆盖 |
| 安装接口兼容 | 支撑面、孔系、定位拓扑和关键尺寸可匹配 | 部分覆盖 |
| CAD定位闭合 | 从非原型位姿经真实配合得到唯一外部位姿 | 已覆盖已发布模板 |
| 空间兼容 | 外形、维护区和其他模组不发生非法冲突 | 独立后验项 |
| 功能/工艺兼容 | 轨道、载具、光轴、工作区、精度和节拍满足需求 | 尚未普遍覆盖 |

只有角色相同不能推断安装接口兼容；只有安装接口兼容也不能推断功能与工艺等价。

## 3. SS00替换AE00的边界示例

Project01 SS00是双轨传输，Project03 AE00是单轨传输。当前跨项目Case 02完成的是：

- 用SS00的安装支撑面和两个定位孔；
- 对接Project03 AA00原AE00槽位上的支撑面和两个定位孔；
- 建立一个重合和两个同心配合；
- 完成保存、关闭和重开复核。

该结果证明“底部安装接口可建立配合”，不证明：

- 双轨能够满足原单轨工艺；
- 扫描器能覆盖正确轨道；
- 载具、工作位和龙门覆盖等价；
- 包络、维护和碰撞通过。

因此该案例必须标记为机械评审候选，不能描述为已经确认的功能替换。

## 4. 原型依赖边界

默认模式必须满足：

- 新模组由独立CAD文件插入；
- 初始位姿显著区别于原型保存位姿；
- 最终位置只由已发布配合束确定；
- 不使用案例锚点或叶级位姿锚点；
- 欠约束时明确阻断，而不是固定组件补足。

只有工程师明确选择“原型位姿依赖/标定回退模式”时，才允许使用原型位姿信息，并必须在结果中标记`portable=false`或等价说明。

## 5. 当前不能宣称的能力

- 任意两个模组都能自由组合；
- 同功能模组可以无条件互换；
- 全目录模组均已有完整安装端口；
- 所有跨项目案例均通过机械工程合理性评审；
- 完成CAD配合就等于无干涉；
- 静态装配通过就等于动态工艺和生产可用。

## 6. 新跨项目候选的最低检查项

1. 功能角色和具体结构属性，例如单轨/双轨、工位数和载具类型；
2. 双方安装端口拓扑；
3. 定位孔距、支撑高度和接口方向；
4. 配合束能否封闭外部自由度；
5. 非原型初始位姿CAD闭环；
6. 功能端口，例如扫码目标、校准点和工作区；
7. 尚未检查的空间、碰撞和工艺项必须显式列出。

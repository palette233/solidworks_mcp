# 跨项目模组兼容性机械工程确认表

更新时间：2026-10-21

## 1. 评审目的

本表用于确认扫描、清洁/称重、排胶/废胶模组是否需要、以及是否能够跨项目安装。

这里需要判断的不是“两个模组功能名称是否相同”，而是：

> 来源模组能否安装到目标项目的设备环境中；若不能直接安装，是否存在备用槽位，是否允许新增孔位或转接件，以及安装后是否仍满足工艺要求。

详细的当前系统判断和证据见：

- `docs/cross_project_incompatibility_engineering_review-CN.md`

请为每组组合选择一种目标状态：

| 等级 | 含义 | 选择 |

| A 原生直装 | 使用目标项目原生槽位，无须改孔或转接件 | [ ] |
| B 备用槽位安装 | 原生槽位不兼容，但允许使用基座已有的其他孔位 | [ ] |

| D 无需兼容 | 实际业务不会发生该组合 | [ ] |

## 9. 评审完成后软件侧将执行的工作

对于被确认需要支持的组合，软件侧依次完成：

1. 登记模组安装端口和目标槽位端口；
2. 将确认的面、孔、销、槽写入面端点目录；
3. 建立完整、可解释的驱动配合束；
4. 将工艺距离和功能关系登记为只读验证关系；
5. 从明显偏离原型的位置插入模组；
6. 创建真实SolidWorks配合并检查剩余自由度；
7. 保存、关闭、重开并复核配合状态；
8. 更新跨项目兼容矩阵和自然语言候选推荐。

不要求支持的组合将保持失败关闭，不会为了提高兼容数量而生成虚假配合。

# FL9A 去原型位置依赖测试

## 结论

测试通过。求解器在不使用原型组件位置、原型锚点近邻排序和供胶源位置侧向判断的情况下，仅依据真实 CAD 投影尺寸、模组类型、工艺点/区域及空间硬约束，生成了一个与原型不同的可行布局。

该结果证明当前系统已具备“生成新的约束可行相对布局”的基础能力，不再只有原型复原能力。但本测试仍使用 CAD 捕获的投影外形与原始姿态轴，且若干工艺点和行程为临时估计，因此尚不是生产布局。

## 测试方法

1. 设置 `preferSourceLayout=false`、`sourcePositionIndependent=true`。
2. 将龙门锚点归一化到求解坐标原点，不固定到原型 A500 坐标。
3. 对 8 个组件分别施加两组不同的独立二维扰动，同时保持各组件几何尺寸不变。
4. 两次分别求解，并在相对 A100 龙门坐标中比较结果。
5. 要求两次结果一致、与原型显著不同，并通过工艺、空间、行程、非法重叠和 containment relaxation 检查。

测试还消除了两处隐性原型位置依赖：

- 功能点候选不再按“离原始锚点最近”排序，改为优先最大化龙门包含率、再靠近可行区域中心。
- 供胶侧不再从原始位置推断；测试中显式使用工艺侧约束 `preferredSide=low`。

## 结果

| 指标 | 结果 |
|---|---:|
| 两组扰动求解结果最大相对差 | `8.33e-17 m` |
| 与原型最大相对位置差 | `0.7158 m` |
| 与原型相差超过 10 mm 的非龙门组件 | `7/7` |
| 工艺硬约束 | `13/13` |
| 空间硬约束 | `6/6` |
| 阀行程位于龙门内 | 通过 |
| 非允许二维重叠 | `0` |
| containment relaxation | `0` |
| `productionReady` | `false` |

各模组相对原型的位移差：

| 模组 | 与原型相对位置差 |
|---|---:|
| A500 校准 | 0.263 m |
| A180 扫描 | 0.134 m |
| T401 供胶 | 0.676 m |
| A200 CCD | 0.164 m |
| A800 传输 | 0.071 m |
| A700 清洁+称重 | 0.056 m |
| A300 排胶杯 | 0.716 m |

龙门覆盖率为：A800 86.8%、A200/A180/A500/A700/A300 均为 100%。因此新解没有重现旧 Replay 中 A800/A700/A300 大幅跑出龙门的问题。

本轮没有执行 SolidWorks Replay。新解在进入 CAD 前仍需：

1. 将独立求解坐标平移到可 Replay 的固定基准；
2. 对新布局重新计算三维世界包围盒并执行 B-Rep 干涉；
3. 验证最小间隙、阀头运动扫掠体和维护抽出空间；
4. 用真实工艺点、双阀行程、扫描/CCD 光学参数替换临时估计。

## 2026-08-06 约束与 Replay 闭环更新

上述“未执行 Replay”是首次去原型测试的历史状态，现已完成真实 SolidWorks 闭环。新增约束策略如下：

1. 每个组件输出目标 X/Y/Z 完整姿态框架，Replay 后逐轴验证，消除仅靠单轴角度无法识别的 180° 翻转。
2. A500 校准、A700 清洁称重、A300 排胶禁止与 A800 传输实体投影重叠；服务点仍必须进入双阀公共可达区，但不再要求整个服务模组进入阀头轨迹。
3. 功能模组要求 100% 位于龙门投影区；传输和 Portal 型 CCD 使用各自允许的最低重合率，并在保存后的真实 AABB 上再次校验。
4. 为满足工艺可达和实体净空，传输工作包络采用低侧偏置 `181.5 mm`，A700 锚点采用高侧偏置 `51.8 mm`；这些是显式约束参数，不读取原型组件位置。
5. 去原型 Replay 时保留旧顶层配合的抑制状态，防止历史配合覆盖新布局；配合未删除。

最终双扰动结果最大相对差为 `4.44e-16 m`，13/13 工艺约束、6/6 空间约束、非法重叠 0、containment relaxation 0。真实 Replay 的完整结果见 `docs/source_independent_replay_interference-CN.md`。

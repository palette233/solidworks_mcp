# 脚本目录说明

本目录保存命令行入口、数据编译器和可复现实验工具，不保存Node依赖、CAD实体、日志或截图。

常见前缀：

| 前缀 | 含义 |
|---|---|
| `run_` | 执行已定义流程或CAD事务 |
| `compile_` | 编译目录、上下文、DAG或清单 |
| `build_` | 生成端口、候选或证据输入 |
| `capture_` | 从SolidWorks采集几何或状态 |
| `validate_` / `verify_` | 验证现有产物 |
| `finalize_` | 将一次实验整理为闭环证据 |
| `summarize_` | 生成面向用户的摘要 |
| `diagnose_` / `analyze_` | 专项分析，不应作为生产入口 |

新增脚本时应：

1. 使用工作区相对路径或显式参数，不硬编码个人临时目录；
2. 不覆盖原始CAD文件；
3. 输出到被Git忽略的运行目录；
4. 为危险或耗时操作提供`--help`和清晰失败信息；
5. 可复用逻辑优先下沉到`apps/demo-backend/src/demo_backend/`并由测试覆盖。
